# Claude Skills

Custom skills for Claude.

## Skills

- **google-ui-design** — Google Material-inspired UI/UX design principles (layout, typography, color, components, accessibility) for building clean, professional web interfaces.
- **emoji-policy** — Strict no-emoji policy (0% default density) for all UI and written content; use proper icon libraries instead.

Each skill folder contains a `SKILL.md` with the full instructions, and a packaged `.skill` file for direct install into Claude.
